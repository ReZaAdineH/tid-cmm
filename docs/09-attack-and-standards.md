# MITRE ATT&CK and Standards Alignment

MITRE ATT&CK is the behavioural language TID-CMM uses to describe relevant adversary techniques, detection analytics and telemetry requirements. It does not define TID-CMM's maturity model and it is not used as a percentage-completion checklist.

The canonical model is aligned to **MITRE ATT&CK Enterprise v19.2**.

TID-CMM also publishes or maintains mappings to frameworks and standards including:

- NIST Cybersecurity Framework 2.0;
- SOC-CMM;
- ISO/IEC 27001:2022;
- MITRE D3FEND;
- Continuous Threat Exposure Management concepts;
- detection-engineering maturity references.

The purpose of a crosswalk is translation and traceability, not replacement. TID-CMM remains its own detection capability model, while UTIOM remains the overarching security-operations operating model.
