## Canonical logic

**Relevant adversaries → crown jewels and attack paths → in-scope ATT&CK behaviours → required telemetry → assured visibility → engineered detections → adversarial validation → measurable improvement.**

## Important boundary

TID-CMM is the detection measurement module of UTIOM. It does not redefine the UTIOM lifecycle. Its Incident Response domain measures the detection-to-response interface; full response capability belongs to TIR-CMM.
