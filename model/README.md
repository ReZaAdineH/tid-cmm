# TID-CMM Machine-Readable Model Snapshots

The files in this directory include machine-readable TID-CMM model material preserved from earlier public repository versions.

## Important version note

`model/meta.yaml` currently identifies **TID-CMM 1.2.0**. It should therefore be treated as a **historical snapshot**, not silently relabelled as the current 1.5.0 model.

The current canonical public model is **TID-CMM 1.5.0** and the canonical website/API is:

https://tid-cmm.com

The repository will not manufacture a 1.5.0 YAML representation by editing a historical snapshot. A future repository refresh should import the canonical 1.5.0 machine-readable model from the authoritative public API byte-for-byte or through the model's official generation process.

## Why preserve the older snapshot?

Historical model sources are useful for reproducibility, score-comparison research and understanding how constraints and descriptors evolved. Their version identifiers should remain truthful.

For current doctrine, constraints, assessment depth and public model interpretation, use the root README, `docs/`, and the canonical site.
